01ТребованияСогласовать правило для пустого адреса

ИИ уточняет заявкуЕсли адрес пуст, достаточно предупредить менеджера или нужно остановить проведение?

ЗаказчикЗаказ можно провести. С адресом предупреждение не нужно. Черновик можно записать без сообщения.

ИнструментРазрешенный текстовый помощник для черновика заявки.

РезультатРазработчик получает три примера, по которым заказчик примет доработку.

03КодДобавить предупреждение в проведение

ИИ готовит кодПредлагает проверку адреса и текст сообщения для менеджера.

РазработчикСверяет код с объектами конфигурации. Проверяет синтаксис и то, что заказ по-прежнему проводится.

Инструмент1С:Напарник предлагает код. BSL Language Server проверяет исходники на встроенном языке 1С.

04РевьюСверить проведение и черновик

ИИ ищет расхожденияИщет строки, которые могут заблокировать проведение или вывести предупреждение при записи черновика.

РевьюерПроверяет замечания по коду и задаче. Если предупреждение блокирует проведение, возвращает код на исправление.

ИнструментВ хранилище 1С и Git можно сравнивать версии. В GitFlic можно связать проверку с версией.

05ТестыПроверить проведение и сохранение

ИИ готовит сценарииОписывает проведение заказа с адресом и без него, а также запись черновика.

ТестировщикВыполняет их под ролью менеджера в тестовой базе. Для каждого случая сверяет сообщение и состояние заказа.

ИнструментYAxUnit для отдельных правил и Vanessa Automation для действий пользователя.

РезультатОтветственный за выпуск видит версию конфигурации и итоги трех бизнес-сценариев, проверки другой роли и границы заполненности адреса.

06ПоставкаВыпустить проверенное изменение

ИИ готовит описаниеПишет для менеджеров, когда появится предупреждение и можно ли продолжить работу.

Ответственный за выпускСверяет версию с отчетом о тестах, проверяет порядок восстановления и применяет обновление.

ИнструментGitFlic хранит версии и запускает проверки. Команда настраивает обновление базы 1С.

РезультатПоддержка получает номер выпущенной версии и описание изменения для пользователей.

07СопровождениеОтследить предупреждения и обращения

ИИ разбирает обращенияГруппирует обезличенные сообщения менеджеров. Например, выделяет жалобы на предупреждение при записи черновика.

ПоддержкаПроверяет такое обращение на копии базы и связывает его с версией обновления.

ИнструментСистема учета обращений и разрешенный текстовый помощник.

РезультатЕсли ошибка подтвердилась, в работу возвращается заявка с шагами воспроизведения и тестом для следующего выпуска.
