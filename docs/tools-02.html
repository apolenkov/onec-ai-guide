IDE и статические проверки

BSL Language Server

1c-syntax/bsl-language-server дает LSP-диагностику и навигацию для BSL и OneScript. Интеграции есть для VS Code, EDT, SonarQube и других LSP-клиентов. Те же проверки можно запускать в CI. Конкретные правила и пороги качества настраиваются в конфигурации проекта.

Сверяйте релиз и канал на странице Releases, а правила анализа настройте под проект. Лицензия обозначена Other; изучите COPYING.md и папку лицензий до распространения бинарника.

Claude Code plugin для BSL LSP

Плагин 1c-syntax/claude-code-bsl-lsp связывает Claude Code с BSL Language Server. Поддерживает диагностику, переходы к определениям, поиск ссылок, code actions, форматирование и символы для .bsl и .os. Лицензия MIT. При запуске скачивает последнюю версию сервера из GitHub Releases, поэтому для повторяемости фиксируйте версию.

Работает на macOS, Linux и Windows; Windows требует Git Bash или PowerShell 6+. Плагин не устанавливали и диагностику не запускали.

Набор расширений VS Code

vscode-1c-platform-extension-pack включает BSL, команды для проектов и отладки, MCP-вызовы Platform Tools. README заявляет VS Code, Cursor, Windsurf и VSCodium, версия VS Code от 1.60. Лицензия набора MIT; проверьте лицензии включенных расширений отдельно. MCP работает через Platform Tools и не заменяет проверку BSL.

Официальный продукт 1С

1С:Напарник разработчика

1С:Напарник встроен в 1C:EDT. У него есть встроенные навыки документирования, объяснения кода и ревью, а также пользовательские навыки, инструкции и команды. Проектные навыки можно хранить в Git. Для каждого навыка задается набор доступных инструментов. Навыки можно запускать вручную, а Напарник может подбирать их сам.

Версия 1.1.0 вышла в ноябре 2026 года и требует EDT 2025.1+. Напарник работает через интернет и серверы 1С. Поставщик сообщает, что не передает данные сторонним сервисам и не использует их для обучения без согласия. Независимо это не проверялось.

Права настраиваются по категориям и отдельным инструментам. Доступны режимы Только чтение, подтверждения изменений и пользовательские разрешения. До четырех фоновых помощников наследуют права родителя. При отладке агент видит данные ИБ, функция по умолчанию выключена. Руководство указывает бесплатный индивидуальный ключ через портал 1С до 1 февраля 2027 года. Актуальные условия доступа проверяйте у поставщика.

Это продукт 1С с собственным лицензионным соглашением. Источники описывают возможности, но не дают независимых метрик ускорения или снижения дефектов.

Источники: официальное руководство, история версий, официальная страница об ИИ в платформе 1С.

Тестирование

YAxUnit для модульных тестов

YAxUnit запускает модульные тесты 1С, лицензия Apache-2.0. Тестовый набор дает исполняемый критерий приемки для кода агента. Сверяйте совместимость расширения с целевой платформой и конфигурацией, а отчет запуска прикладывайте к карточке изменения.

Источники: репозиторий и релизы YAxUnit, документация. Запускайте тесты на совместимой тестовой базе.

Vanessa Automation для приемочных сценариев

Vanessa Automation запускает функциональные и приемочные сценарии 1С, в том числе Gherkin. Основной проект использует BSD 3-Clause; зависимости имеют собственные условия. Для запуска нужны тестовая база и данные. Используйте ее для проверки пользовательских потоков после изменения логики или формы.

Источники: репозиторий проекта, лицензия BSD 3-Clause.

Бенчмарк моделей

PRISM для генерации кода 1С

PRISM представляет собой исполняемый benchmark кода для OneScript и 1С:Предприятия. Лицензия MIT. PRISM-1 содержит 35 задач, 174 тест-кейса и результаты 65 моделей на 30 октября 2026 года. Синтаксические, функциональные и нагрузочные проверки оценивают синтаксис, семантику, оптимальность и платформенные критерии. Выпуск заморожен, авторы готовят новый набор.

Рейтинг сравнивает модели на своем наборе, но не измеряет скорость и качество вашей команды. Сверьте задачи PRISM со своей практикой, затем сравните модели на одинаковых обезличенных задачах.

Источники: таблица результатов и методика, репозиторий benchmark.

Как применять инструменты в работе команды

В карточке задачи аналитик фиксирует проблему, пользователя, ограничения и критерии приемки. Разработчик находит затронутые объекты, роли, места вызова и требования стандартов, применимые к изменению.

Выбирайте инструмент по задаче. Навыки Напарника доступны в EDT, skill по БСП опубликован в GitHub, bsl-context дает справку по API платформы, BSL Language Server проверяет код в IDE и CI. До правки разработчик записывает ожидаемый тест, после сохраняет diff и результаты проверок.

Тестировщик запускает модульные и пользовательские тесты на тестовой базе. Ревьюер сверяет критерии, права, результаты проверок и побочные эффекты. Для выпуска сохраните версию, отчет тестов и результат наблюдения. Рабочий маршрут от запроса до выпуска, метрики и затраты команды
