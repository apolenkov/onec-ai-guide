IDE и статические проверки

BSL Language Server

1c-syntax/bsl-language-server реализует LSP для BSL и OneScript. Проект описывает диагностику кода, навигацию и интеграции с VS Code, EDT, SonarQube и другими LSP-клиентами. Подключите его до начала работы агента, тогда те же проверки можно запускать на измененных модулях и в CI.

Текущий релиз и канал (stable или prerelease) меняются, поэтому перед установкой сверяйте страницу GitHub Releases и конфигурацию анализатора с принятыми правилами проекта. В репозитории лицензия обозначена Other; изучите COPYING.md и лицензионную папку для точной области распространения. Не считайте наличие исходников разрешением на включение бинарника в продукт.

Claude Code plugin для BSL LSP

Плагин 1c-syntax/claude-code-bsl-lsp связывает Claude Code с BSL Language Server и добавляет диагностику, переход к определению, поиск ссылок, code actions и форматирование для .bsl и .os. MIT-лицензия. Плагин при запуске проверяет GitHub Releases и автоматически скачивает свежую версию сервера. Для воспроизводимой команды стоит выбрать и записать версию BSL LS, а не оставлять обновление незаметным.

Плагин поддерживает macOS, Linux и Windows. В Windows для скриптов нужен Git Bash либо PowerShell 6+. Инструмент ориентирован на Claude Code. Мы не устанавливали плагин и не запускали его диагностики.

Набор расширений VS Code

vscode-1c-platform-extension-pack собирает расширение BSL, команды для проектов и отладки 1С, а также MCP-расширение для вызова команд Platform Tools. В README заявлены VS Code, Cursor, Windsurf и VSCodium. Лицензия самого набора MIT, но лицензии и полномочия каждого входящего расширения нужно проверять отдельно. Пакет подходит команде, выбравшей редактор VS Code-совместимого семейства. Это установочный агрегатор, а не единый инструмент качества.

Официальный продукт 1С

1С:Напарник разработчика

1С:Напарник встроен в 1C:EDT. Руководство описывает встроенные навыки документирования, объяснения кода и ревью, а также пользовательские навыки, которые можно хранить на уровне пользователя, рабочей области или проекта. Проектные навыки можно версионировать в Git. У навыка задается фиксированный набор доступных инструментов. Плагин также поддерживает редактируемые инструкции и шаблоны команд.

Версия плагина 1.1.0 вышла в ноябре 2026 года и требует 1C:EDT 2025.1 или новее. По официальному руководству, Напарник использует серверы 1С и требует интернет-подключения. Руководство говорит, что данные не передаются сторонним сервисам и не используются для обучения без согласия. Эти утверждения описывают продукт поставщика, а не результат независимой проверки.

Права можно настраивать по категориям и отдельным инструментам. Есть режим Только чтение, режим подтверждения записи и пользовательский набор разрешений. До четырех фоновых помощников наследуют права родительского диалога. Доступ к отладке по умолчанию выключен, поскольку на точке останова агент видит данные информационной базы. Руководство указывает, что индивидуальный ключ можно получить через портал 1С бесплатно до 1 февраля 2027 года. Условия и срок доступа могут измениться.

Это официальный продукт с собственным лицензионным соглашением, а не открытая библиотека для включения в другой репозиторий. Материалы 1С описывают возможности продукта, но просмотренные источники не дают независимой количественной оценки ускорения или снижения дефектов. Эффект нужно измерить на задачах команды.

Источники: официальное руководство, история версий, официальная страница об ИИ в платформе 1С.

Тестирование

YAxUnit для модульных тестов

YAxUnit запускает модульные тесты решений 1С и распространяется по Apache-2.0. В SDLC тестовый набор дает агенту исполняемый критерий приемки, если команда определила правила проверки и умеет запускать тесты на подходящей базе.

Источник: репозиторий YAxUnit, официальная документация. Релизы и требования к версии платформы проверяйте в репозитории при выборе версии.

Vanessa Automation для приемочных сценариев

Vanessa Automation предназначена для автоматизации функциональных и приемочных сценариев 1С, в том числе в Gherkin. Репозиторий указывает BSD 3-Clause для основного проекта и содержит зависимости с собственными условиями. Это отдельный слой проверки пользовательского поведения. Его уместность зависит от наличия управляемой тестовой базы, тестовых данных и стабильного способа запускать сценарии в CI.

Источники: репозиторий проекта, лицензия BSD 3-Clause.

Бенчмарк моделей

PRISM для генерации кода 1С

PRISM представляет собой открытый исполняемый benchmark генерации кода для OneScript и 1С:Предприятия. По странице проекта, в PRISM-1 использованы 35 задач, 174 тест-кейса и 65 моделей. Решения проходят синтаксические, функциональные и нагрузочные тесты. Оценка включает синтаксис, семантику, оптимальность и платформенные критерии. Лицензия проекта MIT. На странице указан срез результатов 30 октября 2026 года. Выпуск PRISM-1 заморожен, авторы готовят следующий набор.

PRISM измеряет результат на опубликованном наборе задач. Он не показывает, сколько времени сэкономит команда, как изменится дефектность ее типовых доработок или какая модель лучше работает с конкретной конфигурацией предприятия. Используйте его как входной ориентир выбора модели, затем измерьте модель на обезличенном наборе своих задач.

Источники: таблица результатов и методика, репозиторий benchmark.

С чего начать

Выберите одну доработку. В EDT откройте ее в Напарнике с правами на чтение или дайте другому помощнику выгрузку учебного модуля. Сверьте имена объектов по метаданным, запустите анализатор и проверьте на стенде один пользовательский сценарий. Оцените, сколько времени заняли подбор контекста и исправления.
