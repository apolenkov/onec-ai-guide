Как применять инструменты в работе команды

В карточке задачи аналитик фиксирует проблему, пользователя, ограничения и критерии приемки. Разработчик находит затронутые объекты, роли, места вызова и требования стандартов, применимые к изменению.

Выбирайте инструмент по задаче. Навыки Напарника доступны в EDT, skill по БСП опубликован в GitHub, bsl-context дает справку по API платформы, BSL Language Server проверяет код в IDE и CI. До правки разработчик записывает ожидаемый тест, после сохраняет diff и результаты проверок.

Тестировщик запускает модульные и пользовательские тесты на тестовой базе. Ревьюер сверяет критерии, права, результаты проверок и побочные эффекты. Для выпуска сохраните версию, отчет тестов и результат наблюдения. Рабочий маршрут от запроса до выпуска, метрики и затраты команды
