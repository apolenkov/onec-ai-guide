Skills и набор ролей

1c-ssl-skills: узкий навык по БСП

Переносимый skill для Codex, Claude Code и OpenCode. Содержит skills/bsp/SKILL.md, 24 справки и scripts/bsp_api.py для сверки API с XML-выгрузкой БСП. Лицензия MIT. Автор указывает БСП 3.1.11, для другой версии сверяйте содержание с поставкой.

Проверены тег v0.17 и commit 579d8a49d1a125ce3cb424ede8032118d798d8f3 от 22 ноября 2026 года через GitHub API. Точный файл skills/bsp/SKILL.md. Установку и выполнение не проводили.

Источник: README и состав, лицензия MIT.

ai_rules_1c: правила, команды и роли для разных агентов

Набор процессов, команд и ролей planner, architect, developer, tester, code-reviewer, с навыками тестов и поиска кода. Commit f4dbf88a4d77231bd310f11598515d4b7522ec70 от 26 ноября 2026 года, проверен через GitHub API. Примеры: content/agents/planner.md, content/skills/1c-business-tests/SKILL.md.

README перечисляет Claude Code, Codex, Cursor, OpenCode, DeepSeek Harness, Kimi, Qwen и другие агенты. Инсталлятор переносит команды, адаптеры, правила и навыки в форматы клиента. Набор помогает задать планирование, разработку, тесты и ревью; фактическое применение зависит от клиента, выбранной модели и ее прав.

GitHub API не распознал лицензию, корневой LICENSE не найден. Пакет и команды не запускали. До выяснения лицензии ссылайтесь на оригинал, не копируйте файлы.

Источники: README.md на проверенном commit, каталог ролей, каталог навыков.

MCP с контекстом платформы

bsl-context: локальная справка и валидация BSL

MCP-сервер индексирует shcntx_ru.hbk установленной платформы. Он ищет типы и методы, показывает члены типов, конструкторы и значения перечислений, проверяет вызовы, выражения и целые модули BSL. Также находит зарезервированные имена. Требуются Rust и локальная платформа, справка в репозитории не поставляется. platform_path задают явно, поскольку API зависит от версии.

Доступны stdio и локальный Streamable HTTP. Инструменты работают со справкой и диагностикой, без исполнения BSL в ИБ. Проверьте whitelist и сетевой bind. Лицензия MIT.

Commit ae7e07759d6c1eec6a75b261daa0af67e9298202 от 27 ноября проверен через GitHub API. Тегированной версии нет. Сервер не собирали и не подключали к IDE. См. README.md на commit.

Источники: README и перечень MCP-инструментов, лицензия MIT.
