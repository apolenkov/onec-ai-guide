Skills и набор ролей

1c-ssl-skills: узкий навык по БСП

Это настоящий переносимый skill для ИИ-агентов. В skills/bsp/SKILL.md находится маршрутизатор, рядом 24 справочных файла, а scripts/bsp_api.py сверяет методы, области и диапазоны строк с XML-выгрузкой БСП. Автор указывает поддержку БСП 3.1.11. Есть установщики для Codex, Claude Code и OpenCode. Репозиторий распространяется по MIT. Если поставка использует другую версию БСП, содержание skill сначала нужно сверить с этой поставкой.

Для воспроизводимой проверки выбран тег v0.17 и соответствующий commit 579d8a49d1a125ce3cb424ede8032118d798d8f3. GitHub API указывает дату commit 22 ноября 2026 года. Пример точного файла: skills/bsp/SKILL.md на v0.17. Репозиторий открыт для чтения, релиз содержит установочные архивы. Установку и выполнение skill мы не проводили.

Источник: README и состав, лицензия MIT.

ai_rules_1c: правила, команды и роли для разных агентов

Это более широкий набор процессов и ролей, а не один skill. В commit f4dbf88a4d77231bd310f11598515d4b7522ec70 есть роли planner, architect, developer, tester, code-reviewer, навыки для тестов и поиска кода, команды и адаптеры для нескольких инструментов. Например, точные файлы content/agents/planner.md и content/skills/1c-business-tests/SKILL.md. GitHub API указывает дату commit 26 ноября 2026 года.

README описывает поддержку Claude Code, Codex, Cursor, OpenCode и других агентов. Эффект зависит от того, как выбранный клиент применяет правила и передает полномочия модели. GitHub API не распознал лицензию репозитория, корневой LICENSE не найден. Мы не устанавливали пакет и не проверяли команды на конкретном агенте. До выяснения лицензии ограничьтесь чтением и ссылками на оригинал.

Источники: README.md на проверенном commit, каталог ролей, каталог навыков.

MCP с контекстом платформы

bsl-context: локальная справка и валидация BSL

MCP-сервер индексирует справочную информацию из shcntx_ru.hbk установленной платформы. Документация перечисляет поиск типов и методов, просмотр членов типа и перечислений, проверку вызова метода, проверку выражений и модулей BSL, а также поиск занятых имен. Для сервера нужны Rust и локальная установленная платформа. Файл справки в репозитории не поставляется. Версию платформы задают явно через platform_path, потому что набор методов и сигнатур зависит от релиза платформы.

Сервер предлагает transport через stdio либо локальный Streamable HTTP. В описанном перечне инструментов доступны справочные и диагностические операции, нет исполнения BSL в информационной базе. Для первого пилота это дает контекст API без подключения к рабочим данным. Проверьте включенный whitelist и сетевой bind. Лицензия репозитория MIT.

На дату среза GitHub API вернул commit ae7e07759d6c1eec6a75b261daa0af67e9298202 от 27 ноября 2026 года. Проект не публикует релизной версии. Точный пример: README.md на commit. Commit и дату проверили через GitHub API. Сервер не собирали и не подключали к IDE.

Источники: README и перечень MCP-инструментов, лицензия MIT.
