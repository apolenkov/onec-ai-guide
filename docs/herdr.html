Herdr в пилоте 1С

Herdr удобно открыть на рабочем месте ведущего разработчика. В одном окне видно, какой агент ждет решения, продолжается ли прогон и какую версию кода проверяет коллега. Терминальные процессы остаются на машине после отключения клиента, пока работает сервер. EDT или Конфигуратор можно держать рядом в обычном графическом окне. Устройство Herdr

Одна задача, три панели

Панель Чья работа Что передать дальше
Разработка Ведущий открывает ветку задачи. Агенту дает согласованные критерии, версию платформы и пути к нужным модулям. Разработчик проверяет правку и фиксирует версию. Идентификатор коммита или версии хранилища, список измененных объектов, критерии приемки.
Тесты Тестировщик запускает проверку синтаксиса и сценарии на учебной базе для этой версии. Если тесты выполняет отдельный сервер, в панели достаточно вывести ссылку на конкретный запуск CI и его статус. Протокол с версией сборки, ожидаемыми и фактическими результатами. При ошибке тестировщик прикладывает шаги для воспроизведения под той же ролью.
Ревью Ревьюер открывает сравнение версий, читает постановку и протокол тестов. Если нужен агент, дает ему отдельный контекст и права чтения. Замечание с объектом и шагами проверки либо заключение по версии. Решение о выпуске ответственный записывает в карточке.

Для двух одновременных изменений нужны раздельные рабочие копии. Для параллельных прогонов с записью в регистры нужны и раздельные тестовые базы либо очередь. Панель Herdr сама по себе такой изоляции не создает.

Как повторить

  1. Из каталога учебного проекта открыть отдельную сессию командой herdr session attach onec-pilot. В созданном рабочем пространстве разделить терминал мышью на три панели, дать им названия из таблицы.
  2. В первой панели открыть разрешенный команде терминальный помощник или работать с Git рядом с EDT. Во второй запустить уже знакомую команде команду тестов. В третьей после фиксации версии открыть git show <коммит>. Для хранилища 1С приложить к карточке сравнение версий из Конфигуратора.
  3. Закрыть клиент и вновь подключиться к той же сессии. Статус blocked помогает заметить запрос на ввод. Увидев done, открыть протокол и сверить версию: агент может закончить как с исправлением, так и с описанием ошибки. Состояния агента и сессии, руководство для управления панелями
