Срез публичных материалов на 28 ноября 2026 года.

Astra Developer Platform (ADP) включена в прайс-лист 1С Дистрибьюции с 23 ноября 2026 года. В перечне дистрибьютора есть шаблоны для Go, Java, Python, C#, TypeScript и React. Шаблон для 1С в этом перечне не указан. 1С Дистрибьюция, 25.11.2026. Производитель представил платформу 19 мая. Анонс выпуска, 19.05.2026.

На конференции 25 сентября "Группа Астра" представила портал на Backstage, GitFlic для исходников и проверок, "Боцман" для управления средами и помощника "Астра ИИ [Код]". Поставщик описал связь изменений с проверками и выпуском. Он назвал статический анализ кода (SAST), проверку состава зависимостей (SCA) и проверку работающего приложения (DAST). Итоги "АстраКонф", 29.09.2026.

По заявлению поставщика, платформа может снизить число рутинных заявок в DevOps на 80-90%. Замера для разработки на 1С поставщик не привел. Итоги "АстраКонф".

В сообщении от 25 ноября дистрибьютор описал работу агента. Агент меняет код в отдельной среде и открывает запрос на слияние в GitFlic. Решение о слиянии принимает человек. Описание дистрибьютора.

Для оценки интеграции с 1С проверьте работу со встроенным языком 1С (BSL), средой разработки 1С:EDT и сборкой конфигурации.

Этапы жизненного цикла разработки

Git ведет историю исходников. CI/CD: автоматические проверки, сборка и доставка изменений. Подробнее см. карту этапов.

Этап Публикует Astra/GitFlic Что добавить для 1С
Проект и исходники ADP выдает сервис с репозиторием, CI/CD и записью в каталоге; шаблоны задают стандартный путь разработки. Выбрать формат исходников (EDT или выгрузка конфигурации), закрепить версии 1С/EDT и ветвление. BSL и EDT ADP не называет.
Разработка ADP показывает OpenIDE и "LLM/агенты"; OpenIDE Pro подключает агентов. Добавить средства BSL и метаданных. BSL Language Server выпущен сообществом 1c-syntax, не ADP/GitFlic.
Сборка и тесты GitFlic запускает задания и хранит результаты. В документации описаны конвейер для запроса на слияние (MR pipeline), конвейер проверки результата слияния (Merge Result Pipeline) и отчеты о тестах и проверках безопасности. Конвейер, отчеты в описании конвейера. Подключите к исполнителю заданий (runner) командную строку 1С:EDT (EDT CLI), конфигуратор и тестовую базу. EDT CLI готовит проект к сборке конфигуратором. Команды тестов и формат отчетов задайте отдельно.
Поставка и эксплуатация ADP заявляет среды разработки, тестирования и предпродакшна, стандарт деплоя, откат и наблюдаемость. "Боцман" управляет Kubernetes-кластерами и приложениями. Настроить доставку артефакта 1С, обновление базы, миграции и откат. Kubernetes не подтверждает готовую контейнеризацию платформы или базы 1С.

Документы 1С: сборка CI через EDT CLI, FAQ EDT, сценарное тестирование. Интеграцию с ADP надо проверить и настроить.

Правила слияния и тесты

В GitFlic правила назначения согласующих, запрета одобрения автором и сброса одобрений при новой правке доступны в редакции Enterprise и на gitflic.ru. При проверке последнего конвейера GitFlic допускает слияние со статусами "Успех" и "Предупреждение". Правила слияния. Конвейер результата слияния доступен только в Enterprise. Конвейер.

Задание конвейера может вызвать языковую модель и сохранить предложенное изменение как файл правки. Функция работает только с конвейером слияния. После того как разработчик применяет правку в интерфейсе, GitFlic создает коммит и запускает новые конвейеры. Документация не задает модель или ее поставщика. Источники: LLM-патчи, 06.05.2026, pipeline, правила слияния, справочник CI/CD YAML.

Для допуска к выпуску 1С нужны BSL-проверки, сборка, тесты на отдельной базе и проверка обновления. Такая цепочка в документации ADP/GitFlic не описана.

BSL, EDT, ACP и MCP

MCP (Model Context Protocol) позволяет помощнику обращаться к внешним инструментам. В рассмотренных материалах Astra и GitFlic нет описания интеграции ADP с BSL, 1С:EDT или MCP для 1С.

В опубликованном списке языков OpenIDE BSL не указан.

Плагин AI for OpenIDE в редакции OpenIDE Pro подключает агентов по протоколу подключения агентов к среде разработки (ACP, Agent Client Protocol). В каталоге есть "Астра ИИ Код", Claude Code, Codex, OpenCode и Cursor. Каждый агент работает со своей моделью. Каталог и подключение агентов.

В проекте сообщества 1c-syntax расширение VS Code запускает BSL Language Server с MCP endpoint. Поддержка этой интеграции в ADP требует отдельного подтверждения поставщика. Проверьте версию и передачу контекста. Источники: BSL Language Server, настройки расширения VS Code и MCP.
